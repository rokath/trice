# Trice Documentation

Start with the [Reference Manual](./TriceReferenceManual.md) for setup, examples, CLI options, Structured Logging, Context Enrichment, and complete technical details. A shorter guided User Manual is planned separately.

The [project README](../README.md) introduces Trice. Executable [examples](../examples/) let you try it; the reference manual explains their configuration and output.

The `ref` directory contains images and CLI-help data used by the documentation. `scratchPad` holds internal plans and drafts; its `obsolete` directory is historical material, not current usage guidance.

The former topic forwarding files are archived. Their links are prepared for restoring the files to this directory; no forwarding files are needed to read the reference manual.
